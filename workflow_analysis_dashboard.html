Benefit: Reduce complexity by 25%, eliminate agent coordination overhead
Impact: All 4 agents are currently placeholders - integrate directly into workflow
2. Simplify Task Decomposition
Current: Rule-based decomposition with hardcoded patterns
Simplify: Single LLM call to decompose requirements into tasks
Benefit: More flexible, handles diverse requirements better
Impact: Replace 105-line rule engine with 20-line LLM prompt
3. Remove Compound Engineering "Brainstorm" Step
Current: 5-step workflow (brainstorm → plan → work → review → compound)
Simplify: 3-step workflow (plan → execute → archive)
Benefit: Reduce workflow steps by 40%, faster execution
Impact: Merge brainstorm into planning phase
4. Defer Experience Database Until Production

Impact: Can remove 154 lines of experience management code initially
